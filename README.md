## 🚀 المحاور والميزات الرئيسية

### 1. البوابة القضائية والعدلية (Judicial Gateway)
تضم 7 مسارات قضائية رئيسية متكاملة:
1. **التوثيق العدلي وصكوك RWA:** تسجيل الملكيات العقارية، توليد معرّفات الصكوك المشفرة، وإتاحة التوقيع الحي عبر الشاشة للمشتري والموثق مع دعم الطباعة الرسمية (PDF).
2. **قيد الدعاوى والمحاكم:** قيد القضايا (تجارية، مدنية، جزائية، عمالية) وإصدار أرقام القيد المركزي إلكترونياً.
3. **قضاء التنفيذ والأوامر الذكية:** معالجة السندات التنفيذية وأوامر الحجز والتجميد الفوري.
4. **الوساطة والتراضي الاتفاقي:** تحرير محاضر الصلح والتسوية ذات القوة التنفيذية المباشرة.
5. **التركات وحصر الورثة:** الحسبة الشرعية وقسمة المواريث وتوزيع الأنصبة تلقائياً.
6. **التصديق الدولي (Apostille):** إصدار شهادات التصديق المعتمدة وفق معاهدة لاهاي للوثائق الرسمية.
7. **إدارة الكادر والرقابة الإدارية:** متابعة أداء القضاة وكتاب العدل، توزيع الدوائر، ومراقبة القضايا الجارية والمنجزة.

### 2. المتجر المالي والـ DeFi (ISO 20022 Interbank Escrow)
- إيداع وتداول العملات (USD, YER, YERS, USDT).
- التحويل والتسوية الفورية لصكوك المنظومة:
  - صك الحصص العقارية الموثقة (`RWA Deed`).
  - صك الحساب المشروط القضائي (`Smart Escrow`).
  - رمز الاستخدام السيادي (`ADT Token`).

### 3. مركز التقارير السيادية والمؤشرات اللحظية
- لوحة تحكم تفاعلية مدعومة بمكتبة **Chart.js** لعرض:
  - مؤشرات حركة التوثيق والمعاملات القضائية.
  - إحصائيات التدفقات النقدية وعوائد الخزينة السيادية.
